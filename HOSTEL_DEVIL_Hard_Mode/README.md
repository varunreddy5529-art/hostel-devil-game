# HOSTEL DEVIL — Endless Edition

Original Indian-hostel-themed surprise-trap HTML5 platformer.

## Features
- 10 handcrafted introductory levels, then unlimited deterministic procedural rooms
- Eight rotating color environments and dynamically named rooms
- Procedurally placed gaps, spikes, platforms, moving enemies and surprise traps
- Difficulty escalates across later rooms, capped to remain playable
- Keyboard: A/D or arrows to move; W/Up/Space to jump; R to restart
- Mobile pointer controls, optional sound, progress and deaths saved in localStorage
- Share text through device share sheet or clipboard
- No external dependencies, paid services or server required

## Deploy
Upload all files together to Netlify Drop, Cloudflare Pages or GitHub Pages. Open index.html for local play.

## Important
Endless means procedurally generated, not manually designed infinite unique art. Rooms repeat design motifs and procedural patterns. Difficulty and playability need real device testing. Progress is per browser/device.

## Hard Mode update
Handcrafted rooms 1–10 now include more hazards and moving enemies. Endless rooms increase gap width, enemy count and patrol speed gradually. Jump distances are capped to preserve theoretical reachability; complete manual playtesting is still recommended.
